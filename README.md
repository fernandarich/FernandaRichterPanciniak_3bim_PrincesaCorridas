*🏍️ Princesa Corridas*

*📖 Sobre o Projeto*
O Princesa Corridas é um sistema web desenvolvido para gerenciamento de informações relacionadas ao esporte de Velocross. O projeto permite cadastrar e consultar pessoas, pilotos, motos, categorias e corridas, facilitando a organização dos dados utilizados em eventos e competições.
O sistema foi desenvolvido como atividade da disciplina de Desenvolvimento Web I, utilizando HTML, CSS, JavaScript, Node.js, Express e PostgreSQL.
--------------------------------------------------------------------------------------------

*🎯 Objetivo*
O objetivo do sistema é centralizar o cadastro e a consulta de informações importantes do universo do Velocross, permitindo:
- Cadastro de pessoas;
- Cadastro de pilotos;
- Cadastro de motos;
- Cadastro de categorias;
- Cadastro de corridas;
- Exibição de imagens das motos;
- Navegação simples entre os módulos do sistema.
--------------------------------------------------------------------------------------------

*🛠️ Tecnologias Utilizadas*
Front-End
- HTML5
- CSS3
- JavaScript
Back-End
- Node.js
- Express
Banco de Dados
- PostgreSQL
--------------------------------------------------------------------------------------------

*📄 Páginas do Sistema*

🏠 Menu Principal
Página inicial responsável pela navegação entre os módulos do sistema.

🏍️ Motos
Permite cadastrar, editar, excluir e visualizar motos cadastradas no sistema.

👤 Pessoas
Gerencia os dados das pessoas cadastradas, como nome, cidade, telefone, e-mail e foto.

🏁 Categorias
Realiza o cadastro das categorias utilizadas nas competições de Velocross.
